机械工业出版社译文的《概率论导论》第一章关于星条法的介绍读起来非常晦涩，中文版是这样翻译的：

(Bose-Einstein) 有放回地从 <span class="math"><math><mi>n</mi></math></span> 个对象中抽取 <span class="math"><math><mi>k</mi></math></span> 个，一共有多少种方法？如果不考虑顺序 (只关心每个对象被抽中几次，不关心它们被抽中的顺序)，一共有多少种方法？

**解**：

当考虑顺序时，由乘法法则可知共有 <span class="math"><math><msup><mi>n</mi><mi>k</mi></msup></math></span> 种方法，但这个问题更为复杂，下面通过一个同构问题(同一问题在不同的情境下)来解决它。

先来解决这样一个问题：将 <span class="math"><math><mi>k</mi></math></span> 个无法区分的粒子放进 <span class="math"><math><mi>n</mi></math></span> 个不同的盒子里。即任何方式交换粒子都算作同一种情况，区别只在于每个盒子有多少个粒子。如图1.5所示，任意的结构均可以用分隔符“|”和粒子“⏺”表示。

为有效起见，所有的序列都要以“|”开头和结尾，中间有 <span class="math"><math><mi>n</mi><mo>−</mo><mn>1</mn></math></span> 个“|”和 <span class="math"><math><mi>k</mi></math></span> 个“⏺";反之,任意这样的序列都可以看作是某个结构的有效编码。因此在两个围场中共有 <span class="math"><math><mi>n</mi><mo>+</mo><mi>k</mi><mo>−</mo><mn>1</mn></math></span> 个位置，我们只需要确定在哪上个位置上放“⏺”，所以一共有 <span class="math"><math><mrow><mo>(</mo><mfrac linethickness="0"><mrow><mi>n</mi><mo>+</mo><mi>k</mi><mo>−</mo><mn>1</mn></mrow><mi>k</mi></mfrac><mo>)</mo></mrow></math></span> 种可能。这被叫作Bose-Einstein值，因为物理学家玻色(Bose)和爱因斯坦(Einstein)在1920年做了不可区分粒子的相关研究，用他们的想法成功地预测了一种叫作玻色-爱因斯坦凝聚态(Bose-Einsteincondensate)的陌生物质状态的存在。

关联到原始问题上，可以将每个盒子对应于半个对象之一，然后可将粒子看作选中标记，粒子数对应着总共被选中的次数。例如，一个盒子中有三个粒子就代表这个盒子对应的对象被选中了三次。粒子是无区别的对应着不考虑抽选的顺序，所以原始问题的解就为
<span class="math"><math><mrow><mo>(</mo><mfrac linethickness="0"><mrow><mi>n</mi><mo>+</mo><mi>k</mi><mo>−</mo><mn>1</mn></mrow><mi>k</mi></mfrac><mo>)</mo></mrow></math></span>。

另一个同构问题就是计算机等式 <span class="math"><math><msub><mi>x</mi><mn>1</mn></msub><mo>+</mo><msub><mi>x</mi><mn>2</mn></msub><mo>+</mo><mo lspace="0">.</mo><mo lspace="0" rspace="0.1667em">.</mo><mo lspace="0" rspace="0">.</mo><mo>+</mo><msub><mi>x</mi><mi>n</mi></msub><mo>=</mo><mi>k</mi></math></span> 的解 <span class="math"><math><mo stretchy="false">(</mo><msub><mi>x</mi><mn>1</mn></msub><mo>,</mo><msub><mi>x</mi><mn>2</mn></msub><mo>,</mo><mo lspace="0">.</mo><mo lspace="0" rspace="0.1667em">.</mo><mo lspace="0">.</mo><mo>,</mo><msub><mi>x</mi><mi>n</mi></msub><mo stretchy="false">)</mo></math></span> 的个数，其中 <span class="math"><math><msub><mi>x</mi><mi>i</mi></msub></math></span> 为非负整数。这与之前的问题是等价的，我们可以把 <span class="math"><math><msub><mi>x</mi><mi>i</mi></msub></math></span> 对应为第 <span class="math"><math><mi>i</mi></math></span> 个盒子中的粒子数。

## 原文

把原文找出来对比一下就知道翻译有多离谱：

(Bose-Einstein). How many ways are there to choose k times from a set of n objects with replacement, if order doesn’t matter (we only care about how many times each object was chosen, not the order in which they were chosen)?

*Solution*:

When order does matter, the answer is <span class="math"><math><msup><mi>n</mi><mi>k</mi></msup></math></span> by the multiplication rule, but this problem is much harder. We will solve it by solving an *isomorphic* problem (the same problem in a different guise).

Let us find the number of ways to put <span class="math"><math><mi>k</mi></math></span> indistinguishable particles into <span class="math"><math><mi>n</mi></math></span> distinguishable boxes. That is, swapping the particles in any way is not considered a separate possibility: all that matters are the counts for how many particles are in each box. This scenario is known as a Bose-Einstein problem, since the physicists Satyendra Nath Bose and Albert Einstein studied related problems about indistinguishable particles in the 1920s, using their ideas to successfully predict the existence of a strange state of matter known as a Bose-Einstein condensate.

Any configuration can be encoded as a sequence of |’s and ⏺’s in a natural way, as illustrated in Figure 1.6.

To be valid, a sequence must start and end with a |, and have exactly <span class="math"><math><mi>n</mi><mo>−</mo><mn>1</mn></math></span> |’s and exactly <span class="math"><math><mi>k</mi></math></span> ⏺’s in between the starting and ending |’s; conversely, any such sequence is a valid encoding for some configuration of particles in boxes. Imagine that we have written down the starting and ending |’s, which represent the outer walls, and in between there are <span class="math"><math><mi>n</mi><mo>+</mo><mi>k</mi><mo>−</mo><mn>1</mn></math></span> fill-in-the-blank slots in between the outer walls. We need only choose where to put the <span class="math"><math><mi>k</mi></math></span> ⏺’s (since then where the <span class="math"><math><mi>n</mi><mo>+</mo><mi>k</mi><mo>−</mo><mn>1</mn></math></span> interior |’s go is completely determined). So the number of possibilities is <span class="math"><math><mrow><mo>(</mo><mfrac linethickness="0"><mrow><mi>n</mi><mo>+</mo><mi>k</mi><mo>−</mo><mn>1</mn></mrow><mi>k</mi></mfrac><mo>)</mo></mrow></math></span>. This counting method is sometimes called the *stars and bars* argument, where here we have dots in place of stars.

To relate this result back to the original question, we can let each box correspond to one of the <span class="math"><math><mi>n</mi></math></span> objects and use the particles as “check marks” to tally how many times each object is selected. For example, if a certain box contains exactly 3 particles, that means the object corresponding to that box was chosen exactly 3 times. The particles being indistinguishable corresponds to the fact that we don’t care about the order in which the objects are chosen. Thus, the answer to the original question is also <span class="math"><math><mrow><mo>(</mo><mfrac linethickness="0"><mrow><mi>n</mi><mo>+</mo><mi>k</mi><mo>−</mo><mn>1</mn></mrow><mi>k</mi></mfrac><mo>)</mo></mrow></math></span>.

Another isomorphic problem is to count the number of solutions <span class="math"><math><mo stretchy="false">(</mo><msub><mi>x</mi><mn>1</mn></msub><mo>,</mo><mo lspace="0">.</mo><mo lspace="0" rspace="0.1667em">.</mo><mo lspace="0">.</mo><mo>,</mo><msub><mi>x</mi><mi>n</mi></msub><mo stretchy="false">)</mo></math></span> to the equation <span class="math"><math><msub><mi>x</mi><mn>1</mn></msub><mo>+</mo><msub><mi>x</mi><mn>2</mn></msub><mo>+</mo><mo lspace="0">.</mo><mo lspace="0" rspace="0.1667em">.</mo><mo lspace="0" rspace="0">.</mo><mo>+</mo><msub><mi>x</mi><mi>n</mi></msub><mo>=</mo><mi>k</mi></math></span>, where the <span class="math"><math><msub><mi>x</mi><mi>i</mi></msub></math></span> are nonnegative integers. This is equivalent since we can think of <span class="math"><math><msub><mi>x</mi><mi>i</mi></msub></math></span> as the number of particles in the <span class="math"><math><mi>i</mi><mrow><mspace/><mi>th</mi></mrow></math></span> box.

## 合理的译文

**（玻色-爱因斯坦）**<br>
从 <span class="math"><math><mi>n</mi></math></span> 个对象中有放回地抽取 <span class="math"><math><mi>k</mi></math></span> 次，如果不考虑顺序（即只关心每个对象被抽中了几次，而不关心它们被抽中的先后次序），一共有多少种可能？

**解：**

如果考虑顺序，由乘法法则可知答案是 <span class="math"><math><msup><mi>n</mi><mi>k</mi></msup></math></span>，但这个问题要难得多。我们将通过求解一个**同构问题**（即换个形式但本质相同的问题）来解决它。

考虑这样一个问题：把 <span class="math"><math><mi>k</mi></math></span> 个不可区分的粒子放入 <span class="math"><math><mi>n</mi></math></span> 个可区分的盒子中。也就是说，交换任意两个粒子不产生新的情况；唯一重要的是每个盒子里各有多少个粒子。这种情形被称为玻色-爱因斯坦问题，因为物理学家萨特延德拉·纳特·玻色（Satyendra Nath Bose）和阿尔伯特·爱因斯坦（Albert Einstein）在 1920 年代研究过关于不可区分粒子的相关问题，并利用这些思想成功预言了一种奇异的物质状态——玻色-爱因斯坦凝聚态。

任意一种分配方式都可以自然地用一串由 `|` 和 `⏺` 组成的序列来表示，如图 1.6 所示。

为了表示有效，序列必须以 `|` 开头和结尾，并且在开头和结尾的两个 `|` 之间，恰好有 <span class="math"><math><mi>n</mi><mo>−</mo><mn>1</mn></math></span> 个 `|` 和恰好 <span class="math"><math><mi>k</mi></math></span> 个 `⏺`；反过来，任何满足上述条件的序列都对应着某种有效的粒子分配方案。

想象我们已经把开头和结尾的两个 `|` 写好了，它们代表左右两堵外壁；在它们之间，一共有 <span class="math"><math><mi>n</mi><mo>+</mo><mi>k</mi><mo>−</mo><mn>1</mn></math></span> 个可填入内容的空位。我们只需要决定这 <span class="math"><math><mi>n</mi><mo>+</mo><mi>k</mi><mo>−</mo><mn>1</mn></math></span> 个空位中哪 <span class="math"><math><mi>k</mi></math></span> 个放 `⏺` 即可（因为一旦 `⏺` 的位置确定，中间剩余的 <span class="math"><math><mi>n</mi><mo>−</mo><mn>1</mn></math></span> 个 `|` 的位置也就自动确定了）。因此，方案数为<span class="math"><math><mrow><mo>(</mo><mfrac linethickness="0"><mrow><mi>n</mi><mo>+</mo><mi>k</mi><mo>−</mo><mn>1</mn></mrow><mi>k</mi></mfrac><mo>)</mo></mrow></math></span>。这种计数方法有时被称为星条法（stars and bars），只不过这里用圆点代替了星号。

为了把这个结果联系回原始问题，我们可以把每个盒子对应到 <span class="math"><math><mi>n</mi></math></span> 个对象之一，把粒子当作“勾选标记”，用来记录每个对象被选中的次数。例如，如果某个盒子里有 3 个粒子，就表示该盒子对应的对象被选中了 3 次。粒子不可区分这一点，正好对应了我们不关心对象被选中的顺序。因此，原始问题的答案同样是 <span class="math"><math><mrow><mo>(</mo><mfrac linethickness="0"><mrow><mi>n</mi><mo>+</mo><mi>k</mi><mo>−</mo><mn>1</mn></mrow><mi>k</mi></mfrac><mo>)</mo></mrow></math></span>。

另一个同构问题是：计算方程 <span class="math"><math><msub><mi>x</mi><mn>1</mn></msub><mo>+</mo><msub><mi>x</mi><mn>2</mn></msub><mo>+</mo><mo lspace="0">·</mo><mo lspace="0" rspace="0.1667em">·</mo><mo lspace="0" rspace="0">·</mo><mo>+</mo><msub><mi>x</mi><mi>n</mi></msub><mo>=</mo><mi>k</mi></math></span> 的非负整数解 <span class="math"><math><mo stretchy="false">(</mo><msub><mi>x</mi><mn>1</mn></msub><mo>,</mo><mo lspace="0">.</mo><mo lspace="0" rspace="0.1667em">.</mo><mo lspace="0">.</mo><mo>,</mo><msub><mi>x</mi><mi>n</mi></msub><mo stretchy="false">)</mo></math></span> 的个数。这等价于上面的问题，因为我们可以把 <span class="math"><math><msub><mi>x</mi><mi>i</mi></msub></math></span> 理解为第 <span class="math"><math><mi>i</mi></math></span> 个盒子中的粒子数。

## 这段到底在讲什么？

问题核心：

> 从 <span class="math"><math><mi>n</mi></math></span> 个对象中有放回地抽取 <span class="math"><math><mi>k</mi></math></span> 次，不考虑顺序，只关心每个对象被抽中几次，有多少种结果？

### 等价转化

把它想象成：

- <span class="math"><math><mi>n</mi></math></span> 个可区分的盒子（对应 <span class="math"><math><mi>n</mi></math></span> 个对象）
- <span class="math"><math><mi>k</mi></math></span> 个不可区分的粒子（对应 <span class="math"><math><mi>k</mi></math></span> 次抽取，但顺序不重要）

我们要把 <span class="math"><math><mi>k</mi></math></span> 个相同的粒子放进 <span class="math"><math><mi>n</mi></math></span> 个不同的盒子，每个盒子可以放任意多个（包括 0 个）。一种放法就对应一种“每个对象被抽中几次”的计数结果。

### 编码方式（stars and bars）

用 `|` 表示盒子之间的隔板，用 `⏺` 表示粒子。

例如 <span class="math"><math><mi>n</mi><mo>=</mo><mn>4</mn></math></span> 个盒子，<span class="math"><math><mi>k</mi><mo>=</mo><mn>5</mn></math></span> 个粒子，一种放法是：

- 盒子1：2个粒子
- 盒子2：0个粒子
- 盒子3：3个粒子
- 盒子4：0个粒子

可编码为：

```
| ⏺⏺ | | ⏺⏺⏺ | |
```

- 开头和结尾必须是 `|`（代表左右外壁）
- 中间有 <span class="math"><math><mi>n</mi><mo>−</mo><mn>1</mn><mo>=</mo><mn>3</mn></math></span> 个 `|` 分隔 4 个盒子
- 中间有 <span class="math"><math><mi>k</mi><mo>=</mo><mn>5</mn></math></span> 个 `⏺`

所以总共有 开头和结尾之间的位置数 = <span class="math"><math><mo stretchy="false">(</mo><mi>n</mi><mo>−</mo><mn>1</mn><mo stretchy="false">)</mo><mo>+</mo><mi>k</mi><mo>=</mo><mi>n</mi><mo>+</mo><mi>k</mi><mo>−</mo><mn>1</mn></math></span> 个位置（这些位置放 `|` 或 `⏺`）。

我们只需要从这 <span class="math"><math><mi>n</mi><mo>+</mo><mi>k</mi><mo>−</mo><mn>1</mn></math></span> 个位置中选出 <span class="math"><math><mi>k</mi></math></span> 个放 `⏺`，其余位置自动放 `|`，所以方案数为：

<div class="math">
<math display="block"><mrow><mo>(</mo><mfrac linethickness="0"><mrow><mi>n</mi><mo>+</mo><mi>k</mi><mo>−</mo><mn>1</mn></mrow><mi>k</mi></mfrac><mo>)</mo></mrow></math>
</div>

这就是 stars and bars（星条法） 的标准推导。

### 另外两个同构问题

1. 方程 <span class="math"><math><msub><mi>x</mi><mn>1</mn></msub><mo>+</mo><msub><mi>x</mi><mn>2</mn></msub><mo>+</mo><mo lspace="0">·</mo><mo lspace="0" rspace="0.1667em">·</mo><mo lspace="0" rspace="0">·</mo><mo>+</mo><msub><mi>x</mi><mi>n</mi></msub><mo>=</mo><mi>k</mi></math></span> 的非负整数解个数，也是 <span class="math"><math><mrow><mo>(</mo><mfrac linethickness="0"><mrow><mi>n</mi><mo>+</mo><mi>k</mi><mo>−</mo><mn>1</mn></mrow><mi>k</mi></mfrac><mo>)</mo></mrow></math></span>。
2. 原始问题（有放回、无序抽取）的结果同样是 <span class="math"><math><mrow><mo>(</mo><mfrac linethickness="0"><mrow><mi>n</mi><mo>+</mo><mi>k</mi><mo>−</mo><mn>1</mn></mrow><mi>k</mi></mfrac><mo>)</mo></mrow></math></span>。

## 更符合直觉的讲解

我们用 <span class="math"><math><mi>n</mi><mo>=</mo><mn>3</mn></math></span> 个对象（盒子），<span class="math"><math><mi>k</mi><mo>=</mo><mn>4</mn></math></span> 次抽取（粒子）做示例，把逻辑压缩成三步。

### 问题本质

从 {A, B, C} 中有放回地抽 4 次，不考虑顺序。

例如：抽到 {A, A, B, C} 和 {A, B, A, C} 算同一种结果，我们只关心计数 (A:2, B:1, C:1)。

### 第 1 步：转化为“放粒子进盒子”

把 3 个对象看成 3 个有标签的盒子（A盒、B盒、C盒）。<br>
把 4 次抽取看成 4 个完全相同的粒子（⚫）。  

一种结果（比如 A 被抽中 2 次，B 被抽中 1 次，C 被抽中 1 次）就对应：

```
A盒: ⚫⚫
B盒: ⚫
C盒: ⚫
```

### 第 2 步：用“隔板”编码（stars and bars）

我们用 `|` 分隔盒子，用 `⚫` 表示粒子。

- 盒子数 = 3 → 需要 2 个内部分隔符 `|`（左右外壁不算）
- 粒子数 = 4 → 需要 4 个 `⚫`

编码规则：

```
| ⚫⚫ | ⚫ | ⚫ |
``` 


- 最左和最右的 `|` 是外壁（固定）
- 中间第一个空格（A盒）：⚫⚫ → 2次
- 中间第二个空格（B盒）：⚫ → 1次
- 中间第三个空格（C盒）：⚫ → 1次

所以这个编码对应结果 (A:2, B:1, C:1)。

### 第 3 步：数“填空位置”即可

固定左右外壁后，中间有多少个空位？

- 内部隔板数：<span class="math"><math><mi>n</mi><mo>−</mo><mn>1</mn><mo>=</mo><mn>2</mn></math></span> 个
- 粒子数：<span class="math"><math><mi>k</mi><mo>=</mo><mn>4</mn></math></span> 个<br>
- 总空位数 = <span class="math"><math><mn>2</mn><mo>+</mo><mn>4</mn><mo>=</mo><mn>6</mn></math></span> 个

我们只需要从这 6 个位置中选出 4 个放 `⚫`，剩下的 2 个自动放 `|`。

所以方案数：

<div class="math">
<math display="block"><mrow><mo>(</mo><mfrac linethickness="0"><mn>6</mn><mn>4</mn></mfrac><mo>)</mo></mrow><mo>=</mo><mn>15</mn></math>
</div>


### 通用公式

对任意 <span class="math"><math><mi>n</mi><mo>,</mo><mi>k</mi></math></span>：

<div class="math">
<math display="block"><mrow><mo>(</mo><mfrac linethickness="0"><mrow><mi>n</mi><mo>+</mo><mi>k</mi><mo>−</mo><mn>1</mn></mrow><mi>k</mi></mfrac><mo>)</mo></mrow></math>
</div>

### 验证（n=3, k=4）

所有 15 种结果可以用 (A盒数, B盒数, C盒数) 列出，就是方程 <span class="math"><math><msub><mi>x</mi><mn>1</mn></msub><mo>+</mo><msub><mi>x</mi><mn>2</mn></msub><mo>+</mo><msub><mi>x</mi><mn>3</mn></msub><mo>=</mo><mn>4</mn></math></span> 的非负整数解，正好 15 个。
