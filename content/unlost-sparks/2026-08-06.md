## 一、为什么一上来要讲“差分矩阵”？

翻开 Strang 的《线性代数》，第一章有一节的重点在讲一个叫“差分矩阵”的东西。为什么要在一开始讲这个东西？

Strang 教授故意这样编排。他的核心理念是：线性代数不是一堆符号游戏，它是用来描述“变化”和“累积”的语言。
而“差分矩阵”恰恰是理解这一点最直观的入口——它告诉我们，矩阵乘法本质上就是对一组数据“做操作”，而最简单的操作就是“求相邻两个数的差”。

矩阵乘法 <span class="math"><math><mi>A</mi><mi>x</mi></math></span> 干的事情非常简单：把“整体”当作“变化”。

## 三、微积分的符号到底怎么对应？

如果你学过微积分，知道导数的定义：

<div class="math">
<math display="block"><mfrac><mrow><mi>d</mi><mi>y</mi></mrow><mrow><mi>d</mi><mi>x</mi></mrow></mfrac><mo>=</mo><munder><mo movablelimits="true" lspace="0" rspace="0.1667em">lim</mo><mrow><mi>h</mi><mo stretchy="false" lspace="0" rspace="0">→</mo><mn>0</mn></mrow></munder><mfrac><mrow><mi>f</mi><mo stretchy="false">(</mo><mi>x</mi><mo>+</mo><mi>h</mi><mo stretchy="false">)</mo><mo>−</mo><mi>f</mi><mo stretchy="false">(</mo><mi>x</mi><mo stretchy="false">)</mo></mrow><mi>h</mi></mfrac></math>
</div>

现在我们把它离散化——不取极限，只管有限个点。把所有符号逐一对应起来：

| 微积分（连续） | 线性代数（离散） | 含义 |
| :--- | :--- | :--- |
| 函数值 <span class="math"><math><mi>f</mi><mo stretchy="false">(</mo><mi>x</mi><mo stretchy="false">)</mo></math></span> | 向量元素 <span class="math"><math><msub><mi>x</mi><mi>k</mi></msub></math></span> | 存下来的数据 |
| 当前点 <span class="math"><math><mi>x</mi></math></span> | 下标 <span class="math"><math><mi>k</mi></math></span> | 位置序号 |
| 下一点 <span class="math"><math><mi>x</mi><mo>+</mo><mi>h</mi></math></span> | 下标 <span class="math"><math><mi>k</mi><mo>+</mo><mn>1</mn></math></span> | 下一个位置 |
| 导数 <span class="math"><math><mfrac><mrow><mi>d</mi><mi>y</mi></mrow><mrow><mi>d</mi><mi>x</mi></mrow></mfrac></math></span> | 差分 <span class="math"><math><msub><mi>x</mi><mrow><mi>k</mi><mo lspace="0" rspace="0">+</mo><mn>1</mn></mrow></msub><mo>−</mo><msub><mi>x</mi><mi>k</mi></msub></math></span> | 变化量 |

特别说明： 导数公式里有个分母 <span class="math"><math><mi>h</mi></math></span> 和极限 <span class="math"><math><munder><mo movablelimits="true" lspace="0" rspace="0">lim</mo><mrow><mi>h</mi><mo stretchy="false" lspace="0" rspace="0">→</mo><mn>0</mn></mrow></munder></math></span>。差分矩阵为了方便，直接取了步长 <span class="math"><math><mi>h</mi><mo>=</mo><mn>1</mn></math></span>，并且去掉了分母和极限。所以差分 = <span class="math"><math><mi>f</mi><mo stretchy="false">(</mo><mi>k</mi><mo>+</mo><mn>1</mn><mo stretchy="false">)</mo><mo>−</mo><mi>f</mi><mo stretchy="false">(</mo><mi>k</mi><mo stretchy="false">)</mo></math></span>，就是纯粹的“差值”，而不是“变化率”。

## 四、反过来：逆矩阵就是“积分”

现在反过来。假如我们只知道变化量 <span class="math"><math><mi>b</mi><mo>=</mo><mo stretchy="false">(</mo><mn>1</mn><mo>,</mo><mn>3</mn><mo>,</mo><mn>5</mn><mo stretchy="false">)</mo></math></span>，以及初始值 <span class="math"><math><msub><mi>x</mi><mn>1</mn></msub><mo>=</mo><mn>0</mn></math></span>，想恢复出原来的 <span class="math"><math><mi>x</mi></math></span>：

- <span class="math"><math><msub><mi>x</mi><mn>2</mn></msub><mo>=</mo><mn>0</mn><mo>+</mo><mn>1</mn><mo>=</mo><mn>1</mn></math></span>
- <span class="math"><math><msub><mi>x</mi><mn>3</mn></msub><mo>=</mo><mn>1</mn><mo>+</mo><mn>3</mn><mo>=</mo><mn>4</mn></math></span>
- <span class="math"><math><msub><mi>x</mi><mn>4</mn></msub><mo>=</mo><mn>4</mn><mo>+</mo><mn>5</mn><mo>=</mo><mn>9</mn></math></span>

这个过程就是累加——从一个起点开始，把每一步的变化量一个一个加上去。

在微积分里，由导数求原函数叫积分；在线性代数里，由差分求原向量就是乘以逆矩阵 <span class="math"><math><msup><mi>A</mi><mrow><mo lspace="0" rspace="0">−</mo><mn>1</mn></mrow></msup></math></span>。

所以 Strang 说：

> 差分 <span class="math"><math><mi>A</mi><mi>x</mi></math></span> 变成导数 <span class="math"><math><mfrac><mrow><mi>d</mi><mi>x</mi></mrow><mrow><mi>d</mi><mi>t</mi></mrow></mfrac></math></span>，<span class="math"><math><msup><mi>A</mi><mrow><mo lspace="0" rspace="0">−</mo><mn>1</mn></mrow></msup><mi>b</mi></math></span> 中的累加就变成对 <span class="math"><math><mi>b</mi><mo stretchy="false">(</mo><mi>t</mi><mo stretchy="false">)</mo></math></span> 积分。

## 五、微积分与线性代数对比

我们可以把整个关系画成一张对照表：

|  | 微积分（连续） | 线性代数（离散） |
| :--- | :--- | :--- |
| 正向操作 | 求导 <span class="math"><math><mfrac><mrow><mi>d</mi><mi>y</mi></mrow><mrow><mi>d</mi><mi>x</mi></mrow></mfrac></math></span> | 差分矩阵 <span class="math"><math><mi>A</mi><mi>x</mi></math></span> |
| 反向操作 | 积分 <span class="math"><math><mo lspace="0">∫</mo><mi>b</mi><mspace width="0.16666667em"/><mi>d</mi><mi>t</mi></math></span> | 逆矩阵 <span class="math"><math><msup><mi>A</mi><mrow><mo lspace="0" rspace="0">−</mo><mn>1</mn></mrow></msup><mi>b</mi></math></span> |
| 核心思想 | 从函数提取变化率 | 从向量提取相邻差值 |
| 互逆关系 | 微分和积分互逆 | 矩阵和逆矩阵互逆 |

它们的数学结构一模一样，只是一个在连续世界，一个在离散世界。

## 六、为什么这很重要？

Strang 想通过这一节表达：

> 矩阵不是从天而降的怪物，它就是用来表达“前后变化”的最自然工具。

线性代数不是算术，而是一种看世界的方式。

不过，我并不认为用这样的方式去理解微积分本身是一种好方法。微积分的极限逼近、连续性、无限切分、瞬间变化，才是最自然、最符合直觉的方式。

最后，我认为线性代数开篇应该重点强调的是，只是把一堆简单方程写在了一起而已。
