## Padding

`Segment` 中的 Padding 究竟是做什么的？

```go
type Segment struct {
	Start int
	Stop int
	Padding int
	ForceNewline bool
}
```

假设第一个字符是 tab，那么它占的列宽为 4，但是它只是一个字符。如果要求行首需要空两个列宽，这就有了问题，从 tab 开始跳一个字符，就跳过了 4 列，但是你不可能停在一个字符的中间，字符是离散的，不能有半个，这时候多条了两列，怎么办？用 `Padding` 记下来，`Start` 所在的字符位置，比规定多跳了两列。

## Segment 删除行首空白的问题

这段删除行首空白的代码其实有点问题，`width -= 4`，遇到 `\t` 就当作 4 个空格？但是 `\t` 的宽度并不是固定的，要取决于你在哪里按下的 tab，它可能栈绝4、3、2、1 个列。这个函数基本上只在处理代码块内使用，所以问题不大，代码块内的 tab 一般都是对齐到 4 倍列宽的网格的。

```go
func (t *Segment) TrimLeftSpaceWidth(width int, buffer []byte) Segment {
	padding := t.Padding
	for ; width > 0; width-- {
		if padding == 0 {
			break
		}
		padding--
	}
	if width == 0 {
		return NewSegmentPadding(t.Start, t.Stop, padding)
	}
	text := buffer[t.Start:t.Stop]
	start := t.Start
	for _, c := range text {
		if start >= t.Stop-1 || width <= 0 {
			break
		}
		if c == ' ' {
			width--
		} else if c == '\t' {
			width -= 4
		} else {
			break
		}
		start++
	}
	if width < 0 {
		padding = width * -1
	}
	return NewSegmentPadding(start, t.Stop, padding)
}
```

这里这么写的另一个原因我认为是拿不到行的上下文，因为一个 tab 占据几列，只能从行首开始逐字符扫描算出来。

我们通过例子来理解。假设第一个字符是 `\t`，`width==2`，也就是要求跳过两列到列 2 处（注意这里用了 → 表示 tab 占据的列数，不表示 tab 本身）：

```
012345678 <- col
→→→→Hello
0   12345 <- Index
2         <- width
```

在索引 `0` 处，`width` 最初等于 2，所以需要向前跳，问题是这里跳过一个 `\t` 到了索引 `1` 处，但是跑到了列 `4`，`width -= 4` 后等于 `-2`，相当于多跳了两个空格，用 `Padding` 把这两个多借的空格记下来，假装我还在列 2 处。

所以 padding 处理的含义就是，如果往前跳 n 个列，目标位置停在 `\t` 中间时，字符索引实际多移动了几个列。
